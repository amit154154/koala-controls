# Security

The phone server can control the Mac after pairing. Keep it on a trusted local network and do not expose it directly to the internet.

For a suspected security problem, use a private report through GitHub's security reporting feature if available, or contact the maintainer via the public contact links at https://amit154154.github.io/. Do not put credentials, paired-phone tokens, TLS private keys or personal logs in a public issue. No response-time guarantee is offered.

The app is a personal desktop utility, not a hardened remote-administration service. See [privacy](docs/PRIVACY.md) for the permission and storage model.
