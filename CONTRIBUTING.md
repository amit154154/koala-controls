# Contributing

Start with [development](docs/DEVELOPMENT.md), build locally and run `./scripts/test.sh`. Keep changes focused and explain the user-visible behavior plus the checks you ran.

Preserve existing mappings, paired phones and preferences. Do not clear macOS privacy records, modify emulator/controller settings, capture passwords, or run disruptive window/game tests without explicit user intent. New remote actions need typed validation and bounded parameters.

Keep documentation and the duplicate phone markup in sync. Add original/properly licensed assets only. Do not commit app bundles, recordings, personal configs, keys, tokens or private network information.
